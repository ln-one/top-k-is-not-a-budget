# 3 实验

## 3.1 实验设置

实验使用五个查询集的770条查询：TREC-DL 2019/2020、NFCorpus、SciFact 和 TREC-COVID；另在五轮 TREC-COVID 快照上评估同30条查询。我们回放 bge-small-en-v1.5 与 BM25（\(k_1=0.9\)、\(b=0.4\)）的精确排名，采用等权 RRF、名次贡献 \(1/(59+r)\) 和确定性同分规则。

首先，在校准查询上选择 L，再用于留出查询和后续语料快照。随后，测量完成精确 Top-\(k\) 需要多少次访问，以及每条结果何时得到确认。接着，在相同预算和认证规则下比较 DiBud 与 Balanced；Balanced 交替访问两条排名。预算范围为128至10000，统计前20条与前100条中的认证数量。两种方法均逐条访问，另测试每批64条。

最后，将预算截停与完成精确 Top-20 比较。在校准查询上选择能够保留参考平均 nDCG@20 的90%、95%或99%的预算，再在留出查询上报告实际保留的质量和节省的访问次数。

结果先在查询集内平均，再对各集合等权平均。所报告的95%置信区间使用2000次查询 bootstrap。静态实验使用重建的完整通道排名，770条查询均完成精确 Top-20，所有测试预算的产出均已确定。时间实验沿用冻结的快照排名，不将保存末端视为通道耗尽。

## 3.2 固定深度的迁移

我们评估 \(L\in\{10,20,50,100,200,500,1000,2000,5000\}\)。在同一 MS MARCO 语料上，\(L\) 从20增至5000，使 TREC-DL 2019 的 nDCG@10 从0.6538提高至0.6812，却使 TREC-DL 2020 从0.6424降至0.6243（图1a）。仅改变查询，加深窗口的收益就发生了反转。

对于五轮 TREC-COVID 快照中的同30条查询，最佳测试深度依次为50、100、200、200和5000（图1b）。随后，我们检验历史选择能否迁移：通过五折校准在第一轮选择 \(L\)，再固定用于各轮留出查询。相对完整 RRF，nDCG@10 差从第一轮的−0.0085变为第五轮的−0.0272（95%置信区间：[−0.0699, −0.0058]；图1c）。语料变化后，历史选定的深度未必能维持原有的相对质量表现。

## 3.3 固定 K 的访问成本

固定返回数量并不能稳定访问成本（表1）。TREC-DL 2019 完成精确 Top-20 的访问量中位数为311，P95为196410，最大值为3533518，后两者分别约为中位数的632倍和1.14万倍。TREC-DL 2020 与 TREC-COVID 的 P95 也分别达到中位数的80倍和22倍。因此，需要通过预算直接限制访问量，而非通过 K 间接控制。

## 3.4 同预算下的认证产出

在相同的2048次访问预算下，DiBud 在五个查询集上均比均衡访问确认更多结果（表2）。按集合等权平均，前100条中的认证数量从41.77增至45.05，提高7.86%；前20条中从18.07增至18.18。

## 3.5 相对精确 Top-20 的质量与成本

为衡量直接限制访问量的取舍，比较同一 SNRA 轨迹的两种停止方式：一方直到认证20条，另一方在达到预算或认证20条时停止。质量使用线性增益 nDCG@20，不足20条的位置按零增益计。每集合采用五折校准，在校准查询上选择保留参考平均质量90%、95%或99%的最小预算，再冻结到留出查询。保留比例为平均 nDCG 之比，不将零参考质量查询的比例设为1。

以95%校准目标为例，五集合的留出质量保留比例为95.05%至97.68%，访问量减少65.92%至99.53%（表3、图2）。其中，TREC-DL 2019 保留95.05%的平均 nDCG@20，同时减少99.53%的访问量。较大的节省来自3.3节所示长尾查询的完成成本：预算截停保留了大部分实测相关性收益，并省去了大量等待完整 Top-20 的访问。

在99%校准目标下，TREC-DL 2019、TREC-DL 2020 和 TREC-COVID 分别有5、4、5个校准折未在测试预算内达到目标。更高的质量目标可能需要超出本实验范围的预算。
