\section{Conclusion}
Changing queries and corpora in modern RAG hybrid retrieval make it difficult for a previously selected Top-$L$ depth to preserve its original quality--cost tradeoff. Truncation assigns zero to unobserved cross-channel contributions and can change the fused ranking. Exact fusion removes the dependence on a fixed truncation depth, but completing the same Top-$K$ can still require sharply different numbers of accesses. Access cost therefore needs to be bounded directly through a budget rather than controlled indirectly through $K$.

DiBud takes an access budget directly as input and returns as many results as it can certify within that budget, with the returned prefix matching the RRF ranking over the full lists. Experiments on five query sets reveal long-tailed costs for completing exact Top-20. After budget calibration for 95\% quality retention, held-out queries retain 95.05\%--97.68\% of mean nDCG@20 while using 65.92\%--99.53\% fewer accesses. Selective access allows DiBud to certify more results than balanced access under the same budget, while budgeted stopping bounds accesses per request and avoids the long-tail cost of completing a fixed number of results.
