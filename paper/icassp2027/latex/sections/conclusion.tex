\section{Conclusion}
Diverse queries and evolving corpora make fixed $L$ difficult to transfer in hybrid retrieval for RAG, while completing an exact Top-$K$ still requires a variable number of reads. DiBud takes the read budget directly, bounds unread contributions, and returns the prefix certified within that budget. The output length follows the available evidence. Replays on five query sets show that selective reading increases certified yield at equal budgets. Across corpus snapshots, output lengths change while every delivered prefix remains consistent with the corresponding complete RRF ranking.
