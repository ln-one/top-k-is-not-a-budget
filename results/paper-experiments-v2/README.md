# Depth-transfer results

Figure 2 uses `transfer-grid.csv` for the depth curves and `transfer-summary.csv`
for held-out transfer. Calibration choices, folds, and per-query held-out results
are included. Input manifests preserve the original frozen ranking sources.

The temporal experiment follows the same 30 queries across five TREC-COVID
snapshots, using each snapshot's judgments. Saved prefixes are observation limits.
Static cost and budget comparisons use the separate [complete-ranking results](../paper-experiments-v3/README.md).
